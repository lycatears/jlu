# 软件系统开发综合实践
第六学期必修课，1.5学分，计入保研绩点。

本质上来说，这门课不是一门以【软件开发】为核心的课，而是以Oracle数据库特性为核心，需要你在软件开发过程中应用这些特性。

每次课都有拍照签到，需要和教室合影，最后一次课需要组长去答辩，在学习通提交结课报告、代码、演示视频。

## 采分点
对，没错，这门课是有采分点的。下面列出你需要使用的Oracle特性，并给出使用建议。
- 表：用过数据库的应该都知道，这里就不再赘述了。可以强调一下自己是怎么保证第三范式或者BCNF范式的。
- 用户：你需要用不同的 **Oracle用户账号** 控制权限。
- 表空间：不要使用系统表空间存储数据，用 `USERS` 表空间存储数据，并以 `TEMP` 表空间作为临时表空间。
- 主键、外键：每个表要有自己的主键，并使用外键实现完整性约束。
- 视图：使用视图对普通用户隐藏敏感信息
- 触发器：本课程中数据库【删除】不要使用软删除（比如设置一个 `is_deleted` 字段），建议设计一个触发器，在删除时把要删除的记录放到一个“已删除”表中。
- 索引：为各个表建立索引，优化查询效率。
- 序列：Oracle 11g 没有自动自增主键的功能，需要使用触发器+序列实现。
- 过程、函数：这玩意我也不知道怎么把它安排进去，最后写了一些电子邮件格式验证之类的函数放了进去。
- 大对象：存储图片不要存储oss链接，要用 `BLOB` 类型大对象存储。
- 日期时间：不要用时间戳、字符串存储日期时间，要用Oracle提供的类型。

总之你就当它们是一堆关系户，把他们安排进程序就行了。
