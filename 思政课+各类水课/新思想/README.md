# 新思想
第三学期必修课（23级以及之前是第四学期）必修课，3学分。计入保研绩点。

我在大三之前很少有做笔记的习惯，即使是很重要的专业课也只有OneNote上零碎的手写笔记，思政课就更不用说了。对于这门课，我能提的也只有如下建议了：
- 10 14 13 6 4 4 2 2一定要全部背会，哪怕只有一晚上时间，也要知道这些东西的内容是什么，这样你写大题的时候就可以编车轱辘话上去了。具体这几个数字是什么，请看教材绪论部分。
- 平时分尽可能拿满，这门课3学分，悠着点。课堂展示的PPT做的好看点，用个牛逼的模板。
